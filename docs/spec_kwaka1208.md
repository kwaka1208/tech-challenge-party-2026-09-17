# 「あの日の空 あの日、空には 何が見えていた？」現行仕様書

## 概要

生年月日・時刻・観測地点を指定し、その瞬間の全天星図と観測環境をブラウザで再現するWebアプリです。天体配置、薄明、月光に加え、再解析天候、衛星夜間光、DEM地形を観測可能性へ反映します。

## 入力

- 日付：1900-01-01〜2100-12-31
- 現地時刻：必須
- 観測地点：地名検索、現在地、または緯度経度の手動入力
- IANAタイムゾーン：地点選択時に自動取得、手動変更可能
- 最大表示等級：1.0〜6.5、0.5刻み

実表示限界は選択値、薄明・月光、取得できた天候、光害相当値の最小値です。取得不能な条件は制約から外し、晴天・暗空とは断定しません。

## 恒星・天文計算

- 名称付き主要恒星：59星
- NASA HEASARC BSC5P：3.45より暗く6.5等級以下の8,132レコード
- IAU 1976歳差モデルでJ2000座標を観測日へ補正
- 太陽・月・水星〜土星：Astronomy Engine
- 月相、地方恒星時、地平座標、標準大気差を計算

星表は生成時に取得して同梱します。再生成は`npm run data:stars`を使用します。

## 観測環境

### 過去天候

- API：Open-Meteo Historical Weather API
- 対象：1940-01-01以降、未来と直近5日間を除く
- 変数：雲量、相対湿度、降水量、利用可能な場合は視程
- 時間分解能：1時間
- 空間分解能：約9〜25 km（地点・年代による）
- 扱い：再解析による推定。雲量、降水、湿度、視程から限界等級を制約し、雲のベールをCanvasへ描画

### 光害

- API：NASA GIBS WMS 1.3.0
- レイヤー：`VIIRS_SNPP_GapFilled_BRDF_Corrected_DayNightBand_Radiance`
- 製品：VIIRS Black Marble VNP46A2相当
- 対象：2012-01-19以降
- 空間分解能：約500 m、日次
- 取得：観測地点周辺の32×32 PNGを取得し、公式グレースケールカラーマップから放射輝度を復元
- 扱い：放射輝度からBortle階級相当と限界等級を概算し、夜間の地平線光へ反映
- フォールバック：2012年以前、未来、欠測日は2016-01-01の参照値を使用し、指定当時の値ではないことを明示

### 地形

- API：Open-Meteo Elevation API
- データ：Copernicus DEM 2021 GLO-90
- 解像度：約90 m
- 標本化：方位10°ごと、距離0.25、0.5、1、2、4、8、16、30、50 km
- 計算：観測標高、地球曲率、標準屈折を考慮した最大仰角を地平線プロファイル化
- 反映：恒星・太陽系天体・表示星数に共通可視判定を使用し、Canvasへ地形シルエットを描画
- 制約：建物、樹木、局所遮蔽物、年代による地形変化は含まない

## 非同期・障害処理

- `App`で天候・光害・地形を並列取得
- 入力変更時は`AbortController`で旧リクエストを中止
- request ID照合で古い応答による上書きを防止
- サービスごとに`loading`、`available`、`estimated`、`unavailable`、`error`を保持
- 1サービスの失敗で他の環境条件や天文計算を停止しない
- provider DTOをUI・天文層へ渡さず、`ObservationConditions`へ正規化

## 表示・操作

- 指定日時の太陽高度に応じた昼・薄明・夜の空色
- 等級とB−V色指数に応じた恒星表示
- 天候の雲ベール、光害の地平線グロー、方位別地形シルエット
- 星座線、天体名、太陽・月・惑星のON/OFF
- ドラッグ回転、拡大縮小、表示リセット
- Fullscreen APIによる星空カードの全画面表示
- モバイルでは通常表示・全画面表示のどちらでもDevice Orientation APIの絶対方位と端末姿勢をENUカメラ座標へ変換し、端末を向けた方向の天体を透視投影
- iOSの明示権限、コンパス追従ON/OFF、5秒無応答時の再試行、相対方位しか取得できない場合の手動表示フォールバック
- コンパス追従中はGeolocation APIで現在地を更新し、手動操作との競合を停止
- 表示恒星数、月相、実効限界等級
- 環境条件カードで値、状態、出典、解像度、推定上の注意を表示

## 制約

- 天候は再解析であり地点実測ではない
- Bortle階級は衛星放射輝度からの換算値
- 2012年以前の光害は2016年参照値であり履歴再現ではない
- 地形はDEM由来で建物・樹木を含まない
- 外部APIのCORS、停止、レート制限により一部条件が取得できない場合がある
- 環境API、地名検索、タイムゾーン判定、Webフォントにはインターネット接続が必要
